Política de Privacidad

Última actualización: 19 de octubre de 2026

1. Identidad del Proyecto y Contacto

sismoPA es un proyecto independiente de información y visualización sísmica en Panamá y sus zonas marítimas limítrofes.

La iniciativa opera de forma cívica y autónoma, sin vinculación orgánica con dependencias gubernamentales ni fines comerciales. Para cualquier consulta técnica, comunicación administrativa o solicitud de soporte respecto a la aplicación, se establecen los siguientes datos oficiales de referencia:

  • Nombre del proyecto: sismoPA (pa.sismodata.app)
  • Naturaleza: Proyecto independiente de información y visualización sísmica en Panamá.
  • Correo oficial de soporte: rbtservices507@gmail.com
  • Sitio web oficial: https://sismospma.netlify.app/

2. Declaración de Independencia Institucional

AVISO DE INDEPENDENCIA:
sismoPA es una aplicación independiente de consulta y visualización de información sísmica. No representa oficialmente al Gobierno de Panamá ni al Instituto de Geociencias de la Universidad de Panamá. La información presentada tiene fines informativos y no sustituye los comunicados ni las indicaciones de las autoridades competentes.

3. Finalidad del Tratamiento de Datos

sismoPA fue diseñada con una filosofía estricta de mínima recolección de datos y máxima privacidad para el ciudadano. La aplicación no recopila datos personales, no incluye rastreadores publicitarios ni analítica de terceros, no solicita contraseñas ni creación de perfiles, y no guarda la ubicación geográfica del usuario.

4. Tratamiento de Datos de Ubicación Geográfica (GPS)

La aplicación incluye una función opcional denominada «Cerca de mí», que permite calcular la distancia aproximada entre el usuario y los epicentros de los sismos registrados.

PROCESAMIENTO ESTRICTAMENTE LOCAL EN EL DISPOSITIVO:
  • Consentimiento explícito: La geolocalización solo se activa si el usuario pulsa de forma deliberada el botón o pestaña de ubicación en el navegador.
  • Sin transmisión externa: Las coordenadas de latitud y longitud procesadas JAMÁS se transmiten fuera del dispositivo, ni a Netlify, ni a Supabase, ni a terceros.
  • Sin almacenamiento persistente: Las coordenadas se retienen exclusivamente en la memoria RAM volátil del navegador durante la sesión activa. No se guardan en localStorage, bases de datos locales ni cookies.
  • Cálculo geodésico en el cliente: La distancia se calcula en el propio dispositivo mediante la fórmula matemática de Haversine y se borra de inmediato al salir de la pestaña o cerrar la aplicación.

5. Infraestructura Técnica y Proveedores de Servicios

Para poner a disposición la aplicación y sus datos sísmicos públicos, sismoPA utiliza los siguientes servicios de infraestructura tecnológica. Es importante distinguir entre las conexiones directas del dispositivo del cliente y los procesos internos que ocurren de servidor a servidor:

Proveedor / Servicio Tipo de Conexión Función Datos Técnicos Procesados
Netlify Inc. Cliente → Servidor Alojamiento web perimetral y ejecución de funciones serverless para la entrega de datos sísmicos. Registros técnicos estándar de servidor web (dirección IP pública transitoria, User-Agent, fecha y hora de la petición HTTP) necesarios para la entrega del contenido y la prevención de abusos o ataques DDoS.
Supabase Inc. Servidor → Servidor (Exclusivo) Base de datos del catálogo histórico de sismos públicos. El dispositivo del usuario NO se conecta a Supabase. Las consultas se ejecutan exclusivamente desde el backend de Netlify hacia Supabase. Almacena únicamente parámetros geofísicos públicos.
Instituto de Geociencias (IGC-UP) Servidor → Servidor (Exclusivo) Fuente científica de los datos de la Red Sísmica Nacional. El dispositivo del usuario NO se conecta a los servidores del IGC-UP. La función programada de Netlify descarga los registros técnicos abiertos periódicamente.
OpenFreeMap Cliente → Servidor Descarga de teselas vectoriales de mapa de código abierto. Peticiones HTTP directas desde el navegador para descargar teselas cartográficas ($z, x, y$) correspondientes a la vista en pantalla, con la dirección IP del cliente para la entrega de red.
OpenStreetMap Cliente → Servidor Proveedor de respaldo cartográfico y datos geográficos abiertos. Peticiones HTTP directas en caso de respaldo de teselas raster, procesadas bajo la infraestructura de OpenStreetMap.
Google Fonts Cliente → Servidor Descarga de fuentes tipográficas web de lectura accesible (Rubik e IBM Plex Mono). Peticiones HTTP estándar para la entrega de archivos de fuentes (Woff2).
UNPKG (Cloudflare) Cliente → Servidor Distribución CDN de librerías de código abierto (Leaflet y MapLibre GL). Peticiones HTTP para entrega de archivos estáticos de visualización.

Tratamiento técnico de metadatos de red y distinción frente a recopilación de datos: Los metadatos de red (tales como la dirección IP de conexión, User-Agent, fecha y hora de la solicitud HTTP) son procesados exclusivamente por los proveedores de infraestructura perimetral (Netlify, OpenFreeMap, OpenStreetMap, Google Fonts y UNPKG) en sus respectivos servidores de borde. Este procesamiento es intrínseco al funcionamiento técnico de la red Internet bajo el protocolo HTTP/HTTPS y tiene como únicos fines la entrega de los contenidos solicitados, el enrutamiento de paquetes y la mitigación de ataques o abusos cibernéticos (DDoS).

sismoPA no consolida, no asocia a identidades, no almacena en bases de datos ni recopila estos metadatos de red como datos de usuario. Por este motivo técnico y normativo, en la declaración de Seguridad de los Datos (Data Safety) de Google Play Store se establece con fundamento que la aplicación no recopila datos de usuario, complementando dicha declaración con la divulgación transparente de los proveedores de infraestructura en este documento.

6. Permisos de la Aplicación Android

La versión Android de sismoPA (pa.sismodata.app) opera como una Trusted Web Activity (TWA) y limita sus permisos a lo estrictamente indispensable:

  • POST_NOTIFICATIONS (Android 13+): Permiso de sistema reservado para la futura habilitación de notificaciones push de alerta sísmica temprana. La versión 1.0.x no emite alertas en segundo plano; el permiso se encuentra preparado para futuras actualizaciones sin requerir permisos invasivos.
  • Sin permisos invasivos: La aplicación NO solicita acceso a la cámara, micrófono, almacenamiento interno, contactos, mensajes ni ubicación en segundo plano (Background Location).

7. Almacenamiento Local y Caché de la Aplicación

sismoPA utiliza tecnologías estándar de Progressive Web App (Service Worker y CacheStorage) para almacenar localmente en el dispositivo los archivos de la interfaz (código HTML, CSS, JavaScript e iconos). Esto permite que la aplicación cargue de forma instantánea y funcione en condiciones de conectividad inestable. Esta caché contiene exclusivamente archivos estáticos de software y datos sísmicos públicos en caché temporal; no contiene información personal.

8. Seguridad de la Información

Todas las comunicaciones entre la aplicación y los servidores se realizan a través de conexiones cifradas seguras mediante el protocolo HTTPS / TLS (Transport Layer Security), protegiendo la integridad de los datos frente a interceptaciones o manipulaciones intermedias.

9. Derechos de los Usuarios y Contacto

Dado que sismoPA no recopila, no registra ni almacena datos personales de sus usuarios en bases de datos, no existen perfiles individuales que rectificar o suprimir. No obstante, cualquier consulta, observación técnica o solicitud relacionada con la privacidad y funcionamiento de esta aplicación puede ser remitida directamente a la dirección oficial de soporte y contacto: rbtservices507@gmail.com.
